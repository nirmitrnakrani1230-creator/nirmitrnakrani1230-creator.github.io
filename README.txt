HISAAB – how to put it online so it installs on your phone (free, about 5 minutes)

Option A – Netlify Drop (easiest, needs a laptop/computer once)
1. Unzip this folder on a computer.
2. Open https://app.netlify.com/drop and drag the "hisaab-app" folder onto the page.
3. Sign up free when asked so the site stays online. You get a link like https://something.netlify.app
4. Open that link in Chrome on your phone → tap "Install" (or ⋮ menu → Add to Home screen / Install app).

Option B – GitHub Pages
1. Create a free GitHub account and a public repository named hisaab.
2. Upload all files from this folder (Add file → Upload files) and commit.
3. Settings → Pages → Source: "Deploy from a branch", branch main, folder / (root) → Save.
4. After a minute open https://YOUR-NAME.github.io/hisaab/ on your phone and install it.

Your data stays only on your phone. Use Backup → Save backup file every week or so.
To update the app later, replace index.html with the new one; your data is not touched.
